## Что это

Аналитическая система для маркетологов. Она считает risk-score каждого клиента по его
услугам, балансам и платежам, объясняет причину простыми словами и показывает,
сколько выручки бизнес может потерять в ближайший горизонт.

## Архитектура

Микросервисы на событийной шине NATS JetStream, гейтвей Traefik, PostgreSQL и Redis,
панель на React, наблюдаемость через Prometheus и Grafana, вход по паролю или через
OIDC (Keycloak). Запуск через Docker Compose, промышленное развёртывание через Helm.

| Сервис | Назначение |
|---|---|
| `ingest` | приём снимков и потоковых изменений исходных данных |
| `scoring` | расчёт risk-score, причин и денежной оценки |
| `api` | REST API рейтинга, аналитики и настроек модели, `/metrics` |
| `auth` | вход, сессии, OIDC |
| `notifier` | живые обновления панели через SSE |
| `simulator` | расширенные демо-данные и поток изменений |
| `web` | панель маркетолога |

Контракты API и событий лежат в [`contracts/`](contracts/).
